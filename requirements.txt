# NOTE: numpy is held < 2.0 to match the reference environment recorded in

# this pin -- "numpy 2.x breaks the torch<->numpy bridge" -- applied to torch
# 2.2-era builds compiled against numpy 1.x, and is obsolete for any torch
# built against numpy 2. Keep the pin here for reference-parity, not for that.
