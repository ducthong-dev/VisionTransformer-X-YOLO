#   LOCAL  macOS / Apple Silicon, CPU or MPS
#   COLAB  Linux / NVIDIA CUDA

# build and pinning would force a multi-GB reinstall. Install torch from the
# environment's own channel first, then this file.

# torch 2.2 builds ("Failed to initialize NumPy: _ARRAY_API not found").

# Pillow is PINNED, not floated. The `jpeg` corruption round-trips through

# is reproducible on any conforming build. Verify with:
#     python scripts/verify_reproducibility.py --check

# drop the family -- do not ship a partially-divergent benchmark.
